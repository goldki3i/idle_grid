# MVP: PC방 유휴 노드 분산 실행 시뮬레이터

PC방 유휴 GPU 플랫폼의 핵심 흐름(작업 분할, 분배, 손님 착석 시 체크포인트 저장, 다른 노드에서 재개)을
표준 라이브러리만으로 구현한 최소 데모입니다. Python 3.9+ 필요, 설치할 패키지 없음.

## 실행

```bash
python run_demo.py                      # 마스터 1 + 워커 자동 실행, 단일 노드와 비교
python run_demo.py --workers 4 --seat-prob 0.05   # 워커 수, 착석 확률 조절
```

실제로 PC를 여러 대로 나눠 돌리려면:

```bash
python master.py --port 8000                                   # 마스터 PC
python worker.py --id pc-01 --master http://<마스터IP>:8000    # 각 워커 PC
curl -X POST http://<마스터IP>:8000/submit -d '{"total_steps":240,"chunks":12}'
curl http://<마스터IP>:8000/status
```

워커 폴더에 `seat_pc-01` 파일을 만들면 해당 워커에 손님 착석을 수동으로 발생시킬 수 있습니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `master.py` | 작업을 조각으로 분할, 워커에 분배, 체크포인트 저장, 응답 없는 워커 회수(lease 5초), 결과 병합 |
| `worker.py` | 조각을 받아 step 단위로 실행, 2 step마다 체크포인트 전송, 착석 시 저장 후 반환 |
| `common.py` | 작업 정의(몬테카를로 pi 추정). step별 시드를 고정해 어느 노드에서 재개해도 결과가 같음 |
| `run_demo.py` | 단일 노드 기준선과 분산 실행을 비교하고 결과 일치 여부를 검증 |

## 검증하는 것

- 중간에 중단되고 다른 노드에서 이어서 실행해도 최종 결과가 단일 실행과 정확히 일치하는지
- 워커가 응답 없이 사라져도 마지막 체크포인트부터 다시 할당되는지

## 한계 (솔직하게)

- **GPU를 쓰지 않습니다.** CPU 연산으로 스케줄링과 체크포인트 이어하기 로직만 검증하는 시뮬레이션입니다.
- 체크포인트는 프로세스/VRAM 스냅샷이 아니라 **애플리케이션 레벨**(step 번호와 누적값 저장)입니다.
  GPU 상태를 통째로 옮기는 라이브 마이그레이션은 구현하지 않았습니다.
- 착석 감지는 확률과 파일 플래그로 흉내 낸 것입니다. 실제로는 키보드/마우스 입력 감지 에이전트로 교체해야 합니다.
- Docker 샌드박스, 인증, 암호화 통신은 없습니다. 신뢰할 수 없는 코드를 실행하면 안 됩니다.
- 속도 향상은 코어 수와 착석 빈도에 좌우됩니다. 작은 환경에서는 거의 안 나올 수 있습니다.
